# Customer Segmentation Project

## 📌 Project Description
Segment customers based on their behavior and demographics to help businesses run targeted marketing campaigns.

## 🎯 Objective
Group similar customers together using clustering techniques to understand purchase patterns and preferences.

## 🛠️ Tech Stack
- **Language**: Python
- **Libraries**: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Tools**: Jupyter Notebook, Power BI for Visualization

## 🔑 Key Features
- Data Cleaning and Exploratory Data Analysis
- Customer Segmentation using K-Means Clustering
- Analyze purchase patterns and customer preferences  
- Visualize segments and key characteristics using plots and dashboards

## 📊 Expected Outcome
- Identified 4-5 distinct customer segments
- Gained insights for targeted marketing and product recommendations
- Experience in customer analytics, segmentation, and business insights

## 🚀 How to Run
1. Clone the repository
2. Install requirements: `pip install -r requirements.txt`
3. Open `Customer_Segmentation.ipynb` in Jupyter or Google Colab
